5.1 수행과 중복 요청

ECS는 한 대상의 수행을 관리하며 해제 전 다른 대상 등록을 거부합니다. 같은 진행 단계의 중복 요청은 동작을 재전송하지 않습니다. 잘못된 순서·대상·장치 ID는 거부합니다. 수동 수행 중 기존 할당·실행·설치 위치·장비 설정 변경·별도 장치 제어를 차단하며 조회 및 OFF/취소는 허용합니다. 프로세스 재기동 시 이전 수행을 자동 재개하지 않습니다.

조사 중지 전 최신 관측으로 조준을 완료한 동일 고정 대상 수행만 중지 중 계속할 수 있습니다. 표시용 보존 좌표로 신규 수행을 시작하지 않습니다. 중단 요청부터 기존 10초 한도에는 운용자 대기도 포함하며, 초과 시 실패·OFF 요청 후 취소/복구가 필요합니다. 정상 종료만으로 자동 조사 재개하지 않고 1007을 기다립니다.

5.2 관측 상태와 판정 불가

Shared Memory target.status=4/valid=0은 관측 일시중지, 5/0은 재관측 대기, 0/1은 새 관측입니다. 4/5는 표시 전용이며 RDR DE03 TrackState 값이 아닙니다. 새 ID는 기존 ID로 치환하지 않습니다.

실제 재개 확인 후 동일 ID의 새 OBSERVED는 111입니다. 보고 공백·LOST·새 ID만으로 108/HIT를 생성하지 않습니다. 3초 결과 확인 기한 내 근거가 없으면 현재 GUI 호환을 위해 3 Failed로 표시하며 판정 불가 사유를 ECS 로그에 기록합니다. GUI 전용 판정 불가 상태는 후속 개선 항목입니다.

운용자가 실제 모의 표적의 결과를 눈으로 확인했을 때만 ECS 콘솔의 sequence confirm-hit TARGET_ID로 수동 결과를 기록할 수 있습니다. 재개 확인이 끝난 동일 수행의 결과 대기 또는 결과 미확정에서만 허용하며 최신 FCS OFF·무오류, RDR 세션·방출 상태를 검사합니다. 로그에는 source=console_visual_confirmation, GUI에는 108을 전달합니다. 이는 센서 자동 판정이 아닙니다. 111로 이미 재관측된 대상에는 허용하지 않습니다. 현재 GUI는 수동/자동 결과 원인을 별도 표시하지 못하므로 로그로 구분합니다.

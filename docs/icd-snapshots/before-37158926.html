최신 GUI ↔ ECS 구조체 정의

본 문서는 GUI와 ECS 간 Shared Memory 및 Named Pipe 통신에 사용되는 최신 구조체와 데이터 정의를 정리한 문서임.

항목

설정값

Shared Memory 이름

Local\ControlStationMock.SharedMemory.v3

Mutex 이름

Local\ControlStationMock.SharedMemory.Mutex.v3

Named Pipe 경로

\\.\pipe\ECS_NamedPipe

Named Pipe Version

3

개선 및 추가사항

  • RDR, FCS, 대상의 고각/방위각은 float 형식으로 하며, 소수점 한 자리 수 까지이다.

    • 단 ECS<->RDR/FCS 간의 통신에서는 int 형식을 사용하며, 실질적으로 이 값에 / 10을 한 값이 고각/방위각이다.

    • ECS<->GUI 간의 통신에서는 이 값을 변환한 float 형식이 규격이니 주의해야 한다.

  • GUI에서 라이다의 구동/정지를 토글 버튼을 통하여 할 수 있다.

    • 단, 라이다가 정지된 경우 값의 가치를 잃었다고 판단하여 대상 할당을 할 수 없으며, 구동도 NO로 바뀐다.

  • RDR/FCS의 위치를 GUI 상에서 수정할 수 있다.

    • RDR/FCS의 버튼이 토글 상자 형태로 나타나며, X/Y/Z를 각각 설정하고 적용할 수 있다.

    • 해당 값으로 기본적으로 출력되는 값은 현재의 X/Y/Z 좌표이다.

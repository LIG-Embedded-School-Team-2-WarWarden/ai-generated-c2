# 설치 위치 및 팬·틸트 각도 보정

## 현재 동작 (2026-11-15)

별도 RDR/FCS XYZ 위치 보정 개념은 GUI와 ECS에서 제거했다.
좌표 계산과 지도에는 실제 설치 위치만 사용한다. 설치 위치 설정은 장비 설정 창에 유지한다.

메인 FCS 패널에서 팬·틸트 각도 보정(°)을 입력하고 저장한다.
팬은 오른쪽 +, 틸트는 위쪽 +이다. 범위는 팬 −180~180°, 틸트 −90~90°이며 유한한 값만 허용한다.
설정 키는 `installation.camera.fcs_angle_offset_deg: [PAN, TILT, 0]`이고 기본값은 `[0,0,0]`이다.
좌표에서 계산한 명령각에 한 번 더한 뒤 0.1°로 반올림한다. PAN은 0~360°로 정규화한다.
각도 보정은 목표 좌표나 지도 위치를 변경하지 않는다. CLI `fcs point`는 지정한 모터각을 그대로 보낸다.

저장만으로 이동하지 않으며, 변경 시 기존 정렬이 무효화된다. 수행을 취소하고 다시 지정해 조준한다.
수동 수행 중 저장은 거절한다. 0°로 저장하면 각도 보정을 해제한다.

IPC 명령 8/9: 그룹 2는 거리, 3은 RDR 시야각, 4는 FCS 각도 보정이다.
폐기한 그룹 0/1은 조회와 저장 모두 거절한다. 실제 설치 위치는 기존 명령 5로 저장한다.
구형 `rdr_zero`, `fcs_zero` 설정 키는 읽을 때 무시하고 다음 설정 저장에서 삭제한다.
기존 파일의 비영점 값도 좌표나 조준에 영향을 주지 않는다. ECS와 GUI를 함께 업데이트해야 한다.

검증: `test_camera_settings.py`, `test_angle_calibration.py`, `test_installation_persistence.py`,
`test_station.py`, C++ 단위 시험 및 GUI 렌더 시험.

## 설정

기존 ECS `--config` JSON의 `installation.camera`에 다음을 추가한다.

```json
{"rdr_zero":[0,0,0],"fcs_zero":[0,0,0],"ranges":[1.5,10,3]}
```

`ranges` 순서는 RDR 최소 인식 거리, RDR 최대 인식 거리, FCS 최대 촬영 거리다.
모두 m 단위이며 영점 보정은 GUI XYZ 좌표계다. 기존 `devices.*.position`은
설치 위치로 유지한다. 기존 좌표계 변환도 유지한다.
기존 설정에 camera 필드가 없으면 기본값을 사용한다.
`--config`가 없으면 실행파일 옆 `installation.json`에 저장한다.

2026-11-14부터 영점 보정은 설치 위치에 더하는 월드 XYZ 오프셋으로 적용한다.
RDR 보정은 관측 객체의 월드 좌표·필터·목록·지도에, FCS 보정은 카메라 기준 위치와
팬·틸트 계산에 반영한다. 입력은 m 단위이며, +X=동쪽, +Y=북쪽, +Z=위쪽이다.
동일한 값의 반복 적용은 누적되지 않으며 0으로 저장하면 해당 보정을 해제한다.
설치 위치 원본은 보정과 별도로 저장한다. IPC 자산 위치는 원본 설치 위치이며,
GUI는 지도 자산 마커와 범위 미리보기에만 영점 오프셋을 더한다. 객체 좌표는 ECS에서
이미 보정되므로 GUI에서 다시 더하지 않는다. 거리 설정은 표시 용도로 유지한다.
보정 변경은 기존 카메라 정렬을 무효화하므로 다시 할당해야 한다. 적용 자체로 모터를 움직이지 않는다.
저장 실패 시 기존 메모리 좌표와 파일을 유지한다.

## GUI

메인 화면의 위치 입력을 영점 보정 입력으로 변경하고 실제 설치 위치를 별도로 표시한다.
장비 설정 팝업의 설치 위치 두 행과 거리 행은 **행별로 저장**한다.
ECS 성공 응답 후에만 저장 완료를 표시하고 저장값으로 미리보기를 갱신한다.
실패하면 입력은 재시도를 위해 남겨두고 저장값과 미리보기는 유지한다.
미리보기는 XY 평면이며 설치 위치에 영점 보정을 더한 위치를 중심으로 그린다.
Z 보정은 객체 XYZ와 카메라 계산에 반영되며 XY 평면도의 높이는 바꾸지 않는다.

## IPC 호환성

기존 v3 프레임과 요청/응답 길이를 유지한다. 추가 명령:

- 8: 설정 조회. RDR/FCS ID=0, TargetId=그룹(0=RDR 영점, 1=FCS 영점, 2=거리).
  성공 응답의 오프셋 20/24/28은 세 float의 IEEE754 비트다. 이 명령에서는
  기존 FcsId/AssignedTargetId/AssignmentState 의미로 읽지 않는다.
- 9: 같은 그룹의 세 값을 요청 PositionX/Y/Z로 저장. 기존 결과코드 사용.
- 5: 기존 설치 위치 저장 명령 유지.

숫자가 아닌 JSON 값, NaN/Infinity, float 범위 초과, 음수 거리,
RDR 최소보다 작은 최대를 거부한다. 음수 영점/설치 좌표는 허용한다.
임시파일 쓰기와 교체 성공 후에만 메모리 설정을 변경한다.

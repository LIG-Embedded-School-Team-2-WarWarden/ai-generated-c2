# 작업 명세서 — 고정 물체의 첫 좌표와 칼만 필터 좌표 비교

**목적**은 라이다가 고정 물체를 인식했을 때, 여러 관측을 반영한 월드 XYZ가 첫 유효 월드 XYZ보다 실제 물체 위치에 가까운지 확인하는 것이다. 평가는 저장된 좌표 기록에서 수행한다. 산출물은 좌표 비교 결과이며, 실장비 제어 명령 변경은 범위에서 제외한다.

## 1. 판단할 질문

| 질문 | 비교 대상 | 지표 |
|---|---|---|
| 어느 좌표가 실제 위치에 가까운가? | 같은 인식 구간의 첫 유효 월드 XYZ와 필터 XYZ | 독립적으로 측정한 기준점까지의 3차원 거리 오차(cm) |
| GUI 좌표가 얼마나 안정되는가? | 같은 시각의 필터 전·후 월드 XYZ 시계열 | 축별 표준편차와 각 시계열 평균 주변의 3D RMS(cm) |

첫 좌표를 고정하면 표시값의 표준편차는 항상 0이므로, 첫 좌표의 품질은 기준점까지의 오차로 평가한다. 앞서 보고된 3.6%는 흔들림 지표의 개선폭이다.

## 2. 측정 조건과 입력

- 라이다가 같은 ID로 반복 인식하는 고정 물체를 사용하고 좌우 주사를 유지한다. 기준점은 라이다가 객체 위치로 보고하는 지점과 대응하도록 정하고, 같은 월드 좌표계에서 독립적으로 측정한다. 기준점의 정의, XYZ, 측정 방법과 측정 불확도를 기록한다.
- 객체 ID, 수신 시각, OBSERVED/PREDICTED 구분, 유효 상태, 세션, 라이다 설치 원점, 필터 전·후 월드 XYZ와 필터 설정을 보관한다. GUI 표시 자릿수로 반올림하기 전의 값을 사용한다.
- 정지 기록을 약 2분씩 여러 차례 수집한다. 같은 물체가 새로 인식된 구간마다 첫 좌표를 별도로 확보한다. 한 번 인식한 뒤 저장된 첫 좌표를 여러 프레임에서 읽어도 독립적인 반복 측정 횟수는 한 번이다.

## 3. 비교 절차

1. 객체별 연속 인식 구간을 나눈다. 소실·재획득, 세션 변경, 설치 원점 변경, 필터 초기화가 있으면 새 구간으로 분리한다. 동일한 수신 샘플의 반복 표시는 한 번만 센다.
2. 각 구간에서 첫 유효 월드 XYZ를 보관하고, 첫 샘플이 OBSERVED인지 PREDICTED인지 기록한다. 필터는 실제 수신 순서대로 재생한다.
3. 비교 시점은 수집 전에 고정한다. 기본안은 첫 유효 샘플 수신 후 5초가 지난 첫 OBSERVED 시점이다. 그때까지 실제 관측이 3개 미만이면 표본 부족으로 표시한다. 각 구간에서 첫 좌표와 해당 시점 필터 좌표를 동일한 기준점에 대조한다.
4. 위치 오차는 `100 × √((X−X기준)² + (Y−Y기준)² + (Z−Z기준)²)`로 계산한다. 입력 단위는 m, 출력은 cm다. 구간별로 두 오차와 차이를 함께 제시하고, 반복 구간 전체의 중앙값과 최댓값을 보고한다.
5. 흔들림은 같은 OBSERVED 시각끼리 짝지어 필터 전·후를 비교한다. PREDICTED를 포함한 GUI 전체 결과는 별도 행에 표시한다. 설정을 조정한 기록과 최종 판정에 쓸 기록은 분리한다.

## 4. 산출물과 완료 기준

- **구간별 결과표**에 객체 ID, 실제 관측 수, 비교 시각, 첫 XYZ, 필터 XYZ, 기준 XYZ, 두 위치 오차를 포함한다. 제외한 구간 수와 사유도 남긴다.
- **흔들림 결과표**에 비교한 샘플 수, 축별 표준편차, 필터 전·후 3D RMS를 포함한다.
- **최종 판정**은 좌표 안정성과 절대 위치 정확도를 나눠 작성한다. 별도 검증 기록에서 오차가 줄어든 구간과 커진 구간을 모두 보고한다. 두 방식의 차이가 기준점 측정 불확도 수준이면 우열 판정을 보류한다.
- 기준 좌표를 확보할 수 없으면 흔들림 평가까지만 완료하고 절대 위치 정확도는 미평가로 표시한다. 좌표 시험 결과만으로 실장비 지향 정확도 개선율을 산정하지 않는다.

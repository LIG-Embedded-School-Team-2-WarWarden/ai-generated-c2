# 촬영용 FCS 팬·틸트 보정

수정 전 기준 커밋: `eb6da15`.

ECS 콘솔에서 다음 명령으로 조회하고 저장한다. 모든 값의 단위는 도(°)이며 순서는 PAN 영점, TILT 영점, 설치 yaw, pitch, roll이다.

```text
fcs calibration
fcs calibration 1.2 -0.4 0 0 0
fcs calibration 0 0 0 0 0
```

두 번째 명령은 계산된 PAN에 +1.2°, TILT에 -0.4°를 더하는 예시다. 현장 측정값이 아니므로 그대로 적용하지 않는다. 마지막 명령은 보정을 해제한다. 저장 성공 후에만 메모리 설정도 변경된다. 기존 할당이 있으면 정렬을 무효화하므로 GUI에서 대상을 다시 할당한다. 명령 자체는 모터를 움직이지 않는다.

`--config` 파일의 다음 위치에도 직접 설정할 수 있다. 파일 변경은 실행 중 약 500ms 간격으로 확인한다. 설정 파일 없이 실행하면 실행 파일 옆 `installation.json`에 저장한다.

```json
{
  "installation": {
    "devices": {
      "FCS-1": {
        "calibration": {
          "pan_offset_deg": 0,
          "tilt_offset_deg": 0,
          "yaw_deg": 0,
          "pitch_deg": 0,
          "roll_deg": 0
        }
      }
    }
  }
}
```

위는 기존 설정에 병합할 일부 필드다. 기존 observer/effector, role, position과 네트워크 설정은 유지한다. 실제 적용 장비는 `installation.effector`가 지정한다. 누락된 보정 필드는 0이며 숫자가 아니거나 유한하지 않거나 ±180°를 넘으면 거부한다.

## 보정 순서와 부호

1. 기존 RDR/FCS 설치 위치부터 실제 위치와 맞춘다.
2. 설치 자세를 알면 yaw/pitch/roll에 입력한다. yaw 양수는 정면이 북쪽에서 동쪽으로 돌아간 상태, pitch 양수는 정면이 올라간 상태, roll 양수는 오른쪽 축이 올라간 상태다. 장비 로컬 축에서 roll, pitch를 적용하고 세계 좌표에서 yaw를 적용하는 순서다. ECS는 그 역변환으로 대상을 장비 좌표로 옮긴다.
3. 정지한 기준점을 촬영해 남은 각도 차이를 PAN/TILT 영점에 반영한다. PAN 양수는 모터 명령 증가 방향, TILT 양수도 모터 명령 증가 방향이다. 설치 yaw와 PAN 영점을 같은 오차에 중복 적용하지 않는다.
4. 여러 방향과 높이의 기준점을 확인한다. 위치·자세 오차가 있으면 한 점의 영점 조정만으로 다른 방향의 오차가 해결되지 않을 수 있다.

보정 후 마지막 단계에서만 0.1°로 반올림한다. 자동 대상 할당 및 추적 명령에 적용되며 `fcs point TILT PAN` 직접 명령은 모터각 그대로 전달한다. 이벤트 로그에 적용 보정값과 최종 명령각이 기록된다. GUI의 FCS 방향 표시는 기존 모터 피드백 기준을 유지하므로 보정 후 광학축의 세계 방향 표시와는 다를 수 있다.

장비의 기계적 이동범위, 원형 PAN 지원 여부, 실제 정밀도는 이 설정으로 바뀌지 않는다. 이번 변경은 설치·영점 보정이며 추적 주기나 지연 예측은 변경하지 않는다. 실제 보정 수치는 장비에서 측정해야 한다.

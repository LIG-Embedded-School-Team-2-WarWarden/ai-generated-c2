# ECS FCS RDR 시스템 목적과 용어

이 프로젝트는 라이다 기반 장비가 관측한 데이터를 바탕으로 촬영용 짐벌의 방향을 제어하는 시스템이다. RDR이 ECS에 관측 데이터를 보내면, ECS는 이를 바탕으로 어디를 촬영할지 FCS에 명령하고, FCS는 짐벌의 촬영 방향을 제어한다.

아래 용어와 용도는 프로젝트 담당자가 2026년 11월 11일 설명한 내용을 기준으로 한다.

## 구성 요소의 의미

| 이름 | 프로젝트에서의 의미 | 역할 |
| --- | --- | --- |
| ECS | Environment Control System | RDR의 데이터를 받아 촬영 방향 제어에 필요한 처리를 수행하고 FCS에 명령을 전달한다. |
| FCS | Film Control System | ECS의 명령에 따라 촬영용 짐벌이 바라볼 방향을 제어한다. |
| RDR | 라이다 기반 관측 장비의 명칭 | 관측 데이터를 생성해 ECS에 전송한다. |

RDR의 영문 풀네임은 여기서 별도로 정의하지 않는다. 이름만 보고 레이더 장비라고 해석하지 않는다.

## 데이터와 명령의 흐름

```text
RDR 라이다 기반 장비
    │ 관측 데이터
    ▼
ECS Environment Control System
    │ 관측 데이터를 바탕으로 촬영 방향 제어 명령 전달
    ▼
FCS Film Control System
    │ 짐벌 방향 제어
    ▼
촬영용 짐벌이 지정된 방향을 바라봄
```

이 흐름에서 “어디를 찍을지”는 카메라의 촬영 방향을 뜻한다. 촬영 시작·종료나 셔터 제어까지 포함한다는 의미는 아니다.

## 코드와 문서를 읽을 때의 용어 해석

| 코드 또는 표현 | 이 프로젝트에서 읽어야 할 의미 |
| --- | --- |
| `fcs` | Film Control System |
| `target` | 관측 대상 또는 촬영 대상 |
| `assignment` | 대상과 제어 장치 사이의 할당 관계 |
| `point`, 포인팅 | 짐벌이 지정된 방향을 바라보도록 하는 동작 |
| `azimuth`, `elevation`, `pan`, `tilt` | 장비 또는 짐벌의 방향을 나타내는 각도 |

FCS를 Fire Control System으로 풀어 쓰거나, 촬영 방향 제어를 조준·사격통제로 설명하지 않는다. `target`, 각도 필드, `laser` 같은 이름이 등장한다는 이유만으로 무기 용도를 판단하지 않는다. 개별 명령의 구체적인 기능은 해당 구현과 장비 설명을 확인한다.

## 개발과 검토 시 적용할 기준

- 시스템 소개에는 ECS와 FCS의 풀네임, RDR의 라이다 기반 관측 역할을 함께 적는다.
- 설명에는 “관측 대상”, “촬영 대상”, “촬영 방향”, “짐벌 제어”처럼 실제 용도를 드러내는 표현을 사용한다.
- 기존 코드 식별자나 통신 명칭은 이 문서만을 근거로 변경하지 않는다. 설명용 용어와 인터페이스 변경은 구분한다.
- 문맥이 불명확한 기능은 이름으로 단정하지 않고 실제 동작과 장비 용도를 확인한다.

## 재사용할 수 있는 프로젝트 소개

> ECS(Environment Control System)는 라이다 기반 RDR 장비에서 받은 관측 데이터를 처리하고, 촬영용 짐벌이 바라볼 방향을 FCS(Film Control System)에 명령하는 시스템입니다. FCS는 이 명령을 받아 짐벌의 촬영 방향을 제어합니다.
